# Discover Ayodhya – README

## Project Overview
This repository contains a simple HTML webpage titled **“Discover Ayodhya”**, designed to showcase the spiritual and cultural significance of Ayodhya, Uttar Pradesh.

## What I Actually Added to the Repo Folder
- **index.html** – Main webpage with:
  - Intro about Ayodhya as the birthplace of Lord Rama  
  - Key attractions: Shri Ram Janmabhoomi Mandir, Hanuman Garhi, Kanak Bhawan, Sarayu Ghats  
  - Travel tips (best visiting season, booking advice)
  - Lists for top destinations and travel essentials  
  - Definition list of travel-related terms  
  - A table of sample Ayodhya tour packages
- **Images Folder** – Contains pictures like *Ram-Mandir-Ayodhya.jpg* and *kanak-bhavan-temple.jpg* referenced in the HTML.

## Purpose
A compact, beginner-friendly HTML project to practice semantic tags, lists, tables, and linking external resources while presenting a concise travel guide to Ayodhya.
